Quick start

Redeem a code in four steps.

Multiple approved guides confirm the same flow through the ABX control on the top HUD after the tutorial is complete.

Finish the short tutorial first

The codes UI is not available immediately. Several guides confirm the short on-farm tutorial must be completed before the codes control appears — if you cannot find it, finish the tutorial in the beginner guide.

Open the ABX control on the top HUD

Look along the top of the screen for the ABX / Codes button. Guides report slightly different corners of the top bar, so scan the whole top HUD rather than one exact pixel.

Type the code exactly as shown

Enter it into the code field precisely: codes are case-sensitive, and extra spaces or typos will make a valid-looking code fail. Copy-paste carefully if you can.

Press Redeem and check the result

Hit Redeem and read the in-game result. If entry fails, recheck capitalization, spaces, and typos; no other failure reason was approved for publication.

Codes FAQ

When a code will not work.

The checks supported by approved sources.

Why did my code fail?

Check capitalization, stray spaces, and typos — codes are case-sensitive. Also make sure you finished the tutorial, since the codes UI is unavailable before that. This guide does not claim any additional failure cause.

Where exactly is the ABX button?

On the top HUD of the game screen. Guides describe slightly different positions along the top bar, so scan the full top edge after your tutorial is complete.

Is there an official code list anywhere?

The official description does not print a promo-code list. Secondary sources report no dedicated public wiki or Trello for the game and point players to the community Discord and Skandi Studios group.

Do I need codes to progress?

No current code reward was approved for this guide, so it makes no progression claim about codes. Start with the verified buy → eggs → deposit → cash route in the beginner guide.
