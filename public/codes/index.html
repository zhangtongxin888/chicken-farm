How to redeem

Redeem a code in four steps.

The trackers all describe the same steps: open the ABX button in the top-left HUD after the tutorial, then paste the code and press Redeem.

Finish the short tutorial first

A new account cannot see the codes button until the short on-farm tutorial is done. If you cannot find the button, finish the tutorial using the beginner guide.

Click the ABX button at the top-left

The codes button is labelled "ABX", not a gift icon. It sits in the button row at the top-left of the HUD.

Paste the code into "Enter code here..."

Copy the code from the table above. Do not add spaces, and keep any punctuation: freecasssh! needs its exclamation mark. Treat capitalization as exact. THANKSFOR100K is all caps and 50MVisits is mixed case.

Press REDEEM

Cash arrives right away, boosts start their timer and Lucky Blocks go to your inventory.

Codes FAQ

When a code will not work.

The most common reasons a code fails, in order.

Why did my Chicken Farm code fail?

First, check that you finished the tutorial. Next, check spelling, spaces and punctuation, for example the "!" in freecasssh!. Codes work once per account, so switching servers will not let you redeem one again. Trackers also report that codes can stop working without warning, so start with the newest ones.

Did a boost code do nothing?

If a Cash or Egg Boost is already running, a second one is easy to miss. Check the boost timer on your HUD before you assume the code failed.

Did Update 10 add new codes?

No new code was reported with Update 10 (September 5, 2026). update8 and plsbesttier came with Update 8 and are still the newest reported codes. See the Update 10 notes for what did change.

Do I need codes to progress?

No. Codes give short boosts, some Cash and a few Lucky Blocks. Your long-term progress comes from the buy → eggs → deposit → cash loop and from rebirths. Start with the beginner guide, then plan your first rebirth.
